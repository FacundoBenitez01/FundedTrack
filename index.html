Entrá a FundedTrack

Con la nube activada, tus cuentas, operaciones y retiros se sincronizan entre PC y celular. La PC puede estar completamente apagada.

La clave utilizada aquí es la clave pública/publishable de Supabase. Nunca pongas una service_role en FundedTrack.

Activar la nube

Primero conectá tu proyecto Supabase. Solo necesitás hacerlo una vez; después podrás usar FundedTrack desde cualquier navegador.

SQL para crear la tabla

Pegá esto una sola vez en el SQL Editor de Supabase:

create table if not exists public.fundedtrack_workspaces ( user_id uuid primary key references auth.users(id) on delete cascade, accounts jsonb not null default '[]'::jsonb, updated_at timestamptz not null default now() ); alter table public.fundedtrack_workspaces enable row level security; create policy "Users can read own workspace" on public.fundedtrack_workspaces for select using (auth.uid() = user_id); create policy "Users can insert own workspace" on public.fundedtrack_workspaces for insert with check (auth.uid() = user_id); create policy "Users can update own workspace" on public.fundedtrack_workspaces for update using (auth.uid() = user_id) with check (auth.uid() = user_id); grant select, insert, update on public.fundedtrack_workspaces to authenticated;
